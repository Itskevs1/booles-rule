What is Boole's Rule?

Boole's Rule (also called Bode's Rule) is a numerical integration method that approximates the definite integral of a function over an interval using 5 equally-spaced points (4 sub-intervals). It belongs to the family of Newton-Cotes closed formulas.

The Formula

\[ \int_a^b f(x)\,dx \approx \frac{2h}{45}\bigl[7f_0 + 32f_1 + 12f_2 + 32f_3 + 7f_4\bigr] \]

Where:

  • \( h = \dfrac{b-a}{4} \) — the uniform step size
  • \( f_i = f(x_i) \) — function values at equally-spaced points
  • \( x_i = a + ih \) for \( i = 0, 1, 2, 3, 4 \)

Derivation Idea

Boole's Rule is derived by fitting a 4th-degree polynomial through the 5 data points and then integrating that polynomial exactly. The coefficients 7, 32, 12, 32, 7 come from this polynomial integration, weighted to give a total coefficient sum of 90.

Error Analysis

Error \(\approx -\dfrac{8}{945} h^7 f^{(6)}(\xi)\), \quad \xi \in [a,b]

The error involves the 6th derivative of f, meaning Boole's Rule is exact for polynomials of degree 5 or lower. It is significantly more accurate than Simpson's Rule for the same number of points.

When to Use Boole's Rule

  • When you have exactly 4 equally-spaced intervals (5 points)
  • When higher accuracy than Simpson's 3/8 Rule is needed
  • When the integrand is smooth and well-behaved
  • As a building block for composite integration

Comparison with Other Rules

  • Trapezoidal Rule: uses 2 points, exact for degree ≤ 1
  • Simpson's 1/3 Rule: uses 3 points, exact for degree ≤ 3
  • Simpson's 3/8 Rule: uses 4 points, exact for degree ≤ 3
  • Boole's Rule: uses 5 points, exact for degree ≤ 5 ✅

Example 1 — Integrate f(x) = x⁴ from 0 to 2

1
Set up the problem.
We want to compute \(\displaystyle\int_0^2 x^4\,dx\). Using Boole's Rule with \(a=0,\; b=2\).
2
Compute step size h.
h = (2 - 0) / 4 = 0.5
3
Identify x-values and compute f(xᵢ) = xᵢ⁴.
x₀ = 0.0 → f₀ = 0.0000
x₁ = 0.5 → f₁ = 0.0625
x₂ = 1.0 → f₂ = 1.0000
x₃ = 1.5 → f₃ = 5.0625
x₄ = 2.0 → f₄ = 16.0000
4
Apply Boole's Rule formula.
Sum = 7(0) + 32(0.0625) + 12(1) + 32(5.0625) + 7(16)
= 0 + 2 + 12 + 162 + 112 = 288
Result = (2 × 0.5 / 45) × 288 = (1/45) × 288 = 6.4
5
Verify with exact answer.
∫₀² x⁴ dx = [x⁵/5]₀² = 32/5 = 6.4 ✅ Exact!
Since f(x)=x⁴ is degree 4 ≤ 5, Boole's Rule gives the exact result.

Example 2 — Integrate f(x) = sin(x) from 0 to π

1
Set up. Compute \(\displaystyle\int_0^{\pi} \sin(x)\,dx\) with \(a=0,\;b=\pi\).
2
Compute h.
h = (π - 0) / 4 = π/4 ≈ 0.785398
3
Compute f(xᵢ) = sin(xᵢ).
x₀ = 0 → f₀ = sin(0) = 0.000000
x₁ = π/4 → f₁ = sin(π/4) = 0.707107
x₂ = π/2 → f₂ = sin(π/2) = 1.000000
x₃ = 3π/4 → f₃ = sin(3π/4) = 0.707107
x₄ = π → f₄ = sin(π) = 0.000000
4
Apply formula.
Sum = 7(0) + 32(0.707107) + 12(1) + 32(0.707107) + 7(0)
= 0 + 22.627 + 12 + 22.627 + 0 = 57.255
Result = (2 × 0.785398 / 45) × 57.255
= (0.034907) × 57.255 ≈ 1.99857
5
Compare with exact value.
∫₀^π sin(x) dx = [-cos(x)]₀^π = 2.000000
Boole's result ≈ 1.99857 | Error ≈ 0.00143 (0.07%)
Very high accuracy with only 5 points! ✅
